# Spec — odin-pango

## Packages

```
pango/   package pango: generated by runic from pango/rune.yml
pangocairo/   package pangocairo: generated by runic from pangocairo/rune.yml
```

Import through the `pango` collection: `import "pango:<package>"`.

## Surface

Every public declaration of the bound headers (Pango and PangoCairo 1.52.1), named as runic names
them, plus the hand fixes in [PATCHED.md](PATCHED.md). Deprecated API is bound, because
`GLIB_DISABLE_DEPRECATION_WARNINGS` is set when generating.

## Version

The binding records the library version it was generated from. `make test` compares it
with the version macros of the installed headers.
